# Vigía Incubation Framework  
## **Roadmap – Version 1.1 (Planned Release)**  
### **Target Release Window: Q1–Q2 2026**

---

# **Purpose of v1.1**

VIF v1.1 focuses on **operationalization**, **digital enablement**, and **international expansion**—with a special emphasis on **multilingual access (EN/ES)** and **multi‑country implementation**.  
While v1.0 establishes the full methodological foundation, v1.1 aims to expand VIF into a fully deployable **government‑ready system**, complete with curriculum, APIs, accreditation, and forecasting assets.

This release does **not** alter the core of VIF 1.0.  
It extends, deepens, and prepares it for **replication across Latin America and beyond**.

---

# **1. Localization & Internationalization (High Priority — Newly Added)**

## **1.1 Full Spanish Translation of VIF (EN → ES)**  
Translate all content under `core/vif/**`:
- governance chapters  
- evidence & maturity sections  
- MEL logic  
- annex summaries  
- case study templates  
- glossary  

Deliverables:
- Spanish version under `/i18n/es/...`  
- Stable mapping of EN ↔ ES document IDs  
- “Last synced with EN version” metadata per page

## **1.2 Docusaurus i18n Activation**  
Implement bilingual site:
- enable locales: `['en', 'es']`
- navbar language toggle  
- footer links in both languages  
- auto‑versioning support for future updates

## **1.3 Multilingual Support Package (ES/PT Future‑Proofing)**  
Prepare the infrastructure for future Portuguese localization:
- placeholder PT structure  
- language governance rules  
- cross‑language consistency guidelines

# **12. Release Philosophy**
